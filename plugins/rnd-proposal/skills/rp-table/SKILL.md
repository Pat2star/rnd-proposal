# 표 생성 스킬

## 0. 절대 규칙 — 표를 이미지로 만들지 않는다

한글 텍스트 추출에서 **이미지 표는 0자**다(실측).
평가가 LLM 자동 채점이면 **표 내용이 통째로 사라진다.**
표는 언제나 마크다운 표 → 네이티브 `hp:tbl` 로 간다.

그림이 필요하면 `rp-figure` 를 쓴다. 조직도·간트·매트릭스는 **표가 아니라 그림**이다(경로 C).

## 1. 마크다운으로 쓴다

```markdown
**[표 N] 표 제목**

| 열1 | 열2 | 열3 |
|---|---|---|
| 값 | 값 | 값 |
```

조립기가 양식의 `borderFill`·열 폭·머리행 음영을 자동으로 맞춘다.

## 2. 양식 제약을 먼저 확인한다

| 제약 | 확인 방법 |
|---|---|
| **열 수 상한** | 대개 6열. 7열은 1.0p 이상을 먹는다 |
| **표 개수 상한** | `gate_form` F-6b 가 센다 |
| **셀 자수 상한** | 양식마다 다르다(실측 예: 90자). 넘으면 `gate_form` F-4 가 잡는다 |

**열을 늘리지 말고 표를 나눈다.** 실제 계획서가 그렇게 한다.

## 3. 캡션 규칙

- **표는 위, 그림은 아래**에 캡션을 단다
- 번호는 **문서 등장 순서대로** `표 1`·`표 2` … (문자 `표 A` 를 쓰지 않는다)
- **첫 장 연구 요약문 표에는 캡션을 붙이지 않는다**

## 4. 표 앞에 한 줄 요약을 둔다

채점기가 표를 못 읽을 경우를 대비한다. 표가 말하는 결론을 그 위 한 줄에 적는다.

## 5. 검증

```bash
python "$CLAUDE_PLUGIN_ROOT/harness_patches/gate_form.py" --hwpx <문서>.hwpx --md <원고>.md --spec <명세>.json
```

`F-4`(셀 자수·구조) · `F-6a`(열 수) · `F-6b`(개수)를 본다. 전부 통과해야 한다.

## 6. 하지 말 것

- **셀 병합에 기대지 마라.** 마크다운 표에 표현 수단이 없다. 필요하면 표를 나눈다
- **본문 글머리 문자(`◦ - ▪`)를 셀에 직접 입력하지 마라** — `paraPr` 이 자동 렌더한다
- **양식이 준 표를 임의로 추가·삭제하지 마라.** 칸만 채운다
