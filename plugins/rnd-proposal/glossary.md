# 용어 사전

`rp-reviewer`가 용어 일관성 검사에 쓴다. 같은 개념을 다른 말로 부르지 않는다.

## 시스템 용어

| 표준 표기 | 쓰지 말 것 | 뜻 |
|---|---|---|
| 양식 | 템플릿, 서식 | 부처가 배포한 `.hwpx` 원본 |
| form profile | 프로파일, 설정 | 양식에서 추출한 스타일 ID 매핑표 + 작성 규칙 |
| 역할(role) | 스타일 | `heading_1`, `bullet_level_0` 등 MD 계층 ↔ ID 매핑 키 |
| 플레이스홀더 | 자리표시자, 마커 | `[FIG-N: 설명]` |
| 그림 삽입 | 매핑, 결합 계약 | 마크다운 `![](파일명)` + `--image-dir` |
| 품질 게이트 | 검수, 리뷰 | `engine.quality.gate` 5항목 95점 |
| 본문폭 | 텍스트폭, 편집폭 | `text_width` (HWPUNIT). 실측값 우선 |

## HWPX 용어

| 표준 표기 | 뜻 |
|---|---|
| HWPUNIT | 1 mm = 283.465, 1 inch = 7200 |
| `paraPr` / `charPr` | 문단모양 / 글자모양 |
| `borderFill` | 셀 테두리+채움. **1-base**(0번 없음) |
| `linesegarray` | 줄 배치 정보. 한글이 열 때 재계산한다 |
| stub 열 | 표 좌측 회색 라벨열 |

## 도메인 용어 (에너지 시스템)

| 표준 표기 | 쓰지 말 것 |
|---|---|
| 고온 히트펌프 | HTHP, 하이템프 히트펌프 |
| 역브레이턴 사이클 | 리버스 브레이턴, 역Brayton |
| 캐스케이드 | 다단, 이중 사이클 |
| 토핑 사이클 / 보텀 사이클 | 상단/하단 사이클 |
| 열교환기(HX) | 열교환장치, 熱交換器 |
| 팽창기 | 익스팬더, 터보팽창기 |
| 작동유체 | 냉매(사이클 전체를 가리킬 때) |
| 성능계수(COP) | 성적계수 |
